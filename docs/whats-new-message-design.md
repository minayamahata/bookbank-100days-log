## 1. 目的

v1.7.0（R4.5〜R4.7）で追加された5機能——再読の記録・メモの文字装飾・本をつなぐ・
メモ一覧ページ・マンスリーログの共有——を、既存ユーザーと新規ユーザーへ5ページの
カード型アプリ内メッセージで知らせる。リリース単位は **v1.7.0 build 9**。

## 2. 画面構成（確定）

- 背後の現在画面を `Color.black.opacity(0.5)` で暗くする（DESIGN_SYSTEM 1章のモーダル背景）
- 中央に角丸 **24pt** のカード。背景は**ライト `#ECECEC`／ダークは従来のカード色 `#1C1C1E`**
  （このView限定の色。`Color.appCardBackground` のライト値は変更しない）。
  **高さは内容に合わせる**（全高固定にしない。5ページ中最も高いページを非表示計測して
  ページャの高さとし、画面に収まらないときだけ上限を掛ける。**ページ内スクロールはしない**）
- 全ページ右上に **44pt以上** の丸い「×」ボタン（**カード内の最上層**。スワイプ中の
  ページ内容が上に重ならないよう `ZStack` + `zIndex` で閉じるボタンを最前面に置く）
- カード内は上から: 見出し（新機能 01。**カード上辺の余白は狭め=32pt**）→
  タイトル（**上下の余白は広め**）→ 説明（**行間広め・文字色は `.primary`**）→
  画像（**説明との間隔は広め=24pt**）→ ページドット5個（**画像のすぐ下**）→ 操作ボタン
- 1〜4ページのボタンは「次へ」、5ページ目（最終ページ）は「はじめる」
- 「次へ」に加えて左右スワイプでも移動できる（`TabView` + `.page` スタイル、インジケータ非表示で自前ドット）
- 「×」= 一時的に閉じる（状態は変えない）／「はじめる」= 確認済みとして閉じる
- 背景タップでは閉じない
- 最終ページから特定画面への自動遷移はしない
- 開くたびに必ず1ページ目から開始（自動・手動とも）

### 見た目

- タイポグラフィは `.app(...)`（LINE Seed）を使う。画像へ文字は焼き込まない
- 見出し・選択中ドット・最終ページ以外の「次へ」は既存ゴールド
  `PassbookColor.color(for: PassbookColor.goldThemeIndex)`
- 最終ページ「はじめる」は承認イメージの青緑系。既存トークンに該当色がないため、
  **`WhatsNewView` 内だけの用途限定定数** `getStartedColor = Color(hex: "0F8578")`
  （承認イメージの近似。アプリ全体の色体系には追加しない）
- 「次へ」「はじめる」のボタンスタイルは**総合口座の口座カプセルボタンと同じ**
  （`.app(.footnote)`・白文字・padding 水平20/垂直12・`passbookCapsuleGradient(tint:)`。
  tint は次へ=ゴールド、はじめる=青緑）
- 画像は `.resizable()` + `.scaledToFit()` で**カード横幅100%**に置き、9:7を維持し切り抜かない
- カード内は**縦スクロールさせない**（2026-08-20 第3回で `ScrollView` を廃止。
  ページャの高さ上限を超えるアクセシビリティ文字サイズでは下端が切れる——実機確認項目）
- iPad ではカード最大幅 **420pt**
- VoiceOver: 「×」に「閉じる」ラベル、ドット行に「ページ n / 5」、次へ・はじめるは通常のButton
- Reduce Motion 有効時はフェード・ページ送りのアニメーションを行わない

## 5. 表示状態の管理

お知らせ対象バージョンは固定値 **`1.7.0`**（build番号ではない）。
将来の別バージョンはキーにバージョンを含めることで追加できる。

### UserDefaults キー（バージョン単位）

| キー | 型 | 意味 |
|---|---|---|
| `whatsNew.autoShowCount.1.7.0` | Int | 自動表示した回数 |
| `whatsNew.confirmed.1.7.0` | Bool | 「はじめる」で確認済みになったか |

`WhatsNewStore`（`UserDefaults` 注入可）で読み書きする。Preview・テストは
`UserDefaults(suiteName:)` を使い本番領域を汚さない（Previewでは `PreviewRuntime.isActive`
ガードにより自動表示ロジック自体が動かない）。

### 自動表示の規則（`WhatsNewAutoShowPolicy` 純粋関数）

```
shouldAutoShow = hasCompletedOnboarding
              && !hasAutoShownThisLaunch   // 1起動につき1回
              && !isConfirmed              // はじめる済みなら出さない
              && autoShowCount < 3         // 最大3回
```

**実機チェック用の一時スイッチ（2026-08-20）**: `temporarilyAlwaysAutoShow = true` の間は
確認済み・3回上限を無視して毎起動表示する（オンボーディング完了と1起動1回は維持）。
この間は回数を加算せず、保存状態を汚さない。
**2026-08-20 実機チェック完了により false へ復帰済み**（リリース版は必ず false のまま）。

- 表示が**実際に始まった時点**で回数を+1（表示中に終了してもその回は数える）
- 同一起動内の再加算・二重表示は `WhatsNewSessionState.launchSession`
  （`SplashPresentationState` と衝突しない別の小さな起動内状態）で防ぐ。
  バックグラウンド復帰では状態が残るため再表示しない
- 「×」は確認済みにしない → 3回未満なら次回起動時に再表示
- 「はじめる」は1回目でも確認済みにし、以後自動表示しない
- 3回表示後は「はじめる」未押下でも自動表示しない
- 別バージョンの確認済み状態は `1.7.0` の表示を妨げない（キーがバージョン別のため）

### 表示タイミング

- 既存ユーザー: スプラッシュのフェード（0.5秒）完了後に判定・表示
- 新規ユーザー: オンボーディング完了クロージャでの閉じアニメーション後に判定・表示
- スプラッシュ・オンボーディングと同時表示しない
- 起動時マイグレーション・バックアップ処理（`RootView.onAppear`）には触れない

### 設定からの再表示

- 設定メニュー「サービス案内」の**フォントライセンス行より上**に「新機能」行を追加
- 手動表示は自動表示回数へ**加算しない**（`recordAutoShowStarted()` を呼ばない）
- 手動表示でも1ページ目から開始
- 手動の「×」は状態を変更しない。手動の「はじめる」は未確認なら確認済みにしてよい
  （`markConfirmed()` は回数へ影響しない）
- 自動表示3回終了後もいつでも再表示できる
